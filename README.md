# Salary Benchmark KZ — обзор зарплат и C&B

Инструмент собирает открытые данные о зарплатах Казахстана и выдаёт **один HTML-файл-дашборд** в формате обзоров PwC / EY / WTW
(фильтры слева, KPI сверху, модули-вкладки). Только стандартная библиотека Python 3.9+, ничего ставить не нужно;
дашборд работает офлайн, данные никуда не отправляются.

## Модули дашборда
| Модуль | Что делает |
|---|---|
| **Рыночный бенчмаркинг** | Вилки (min/P25/медиана/P75/max) по вакансиям + **официальная зарплата Бюро нацстатистики** по профессиям/отраслям/регионам за 2025–2026, динамика, распределение, льготы (C&B). Кнопка «рыночная точка → в калькуляторы» |
| **AI-маппинг должностей** | Вставьте названия должностей (RU/EN, «Senior Python Developer», «C&B специалист») → роль в классификаторе, профобласть, уровень, ближайшая официальная профессия (НКЗ), рыночная точка, CR. Локальный алгоритм (синонимы → основы слов → TF-IDF → косинус), уверенность высокая/средняя/низкая, можно выбрать другую роль |
| **Свежие срезы рынка** | Квартальные официальные данные 2024 — II кв. 2026: РК (средняя, медиана), отрасли, регионы, к пред. кварталу и к году назад, спарклайны, график; срез вакансий «месяц к месяцу» |
| **Вилки и Compa-ratio** | Рыночная точка → политика (позиционирование, ширина вилки) → вилка min/Q1/середина/Q3/max, CR и позиция в вилке по сотрудникам, грейдовая сетка |
| **Бюджет ФОТ** | Штатное расписание → бюджет по месяцам: оклады, премии, налоги работодателя (ОПВР, СО, ООСМС, СН), льготы, «на руки», сценарий «по рынку» |

## Быстрый старт
```bash
python3 -m sbench collect stat      # официальная статистика stat.gov.kz (без регистрации)
python3 -m sbench collect qsamruk   # вакансии qsamruk.kz
python3 -m sbench build             # → output/dashboard.html
python3 -m sbench demo              # демо: СИНТЕТИЧЕСКИЕ вакансии + реальная официальная статистика → output/dashboard_demo.html
python3 -m sbench collect all       # stat + qsamruk (+ hh, если задан токен)
python3 -m unittest discover -s tests
```

## Источники (все открытые)
| Источник | Что даёт | Статус |
|---|---|---|
| **stat.gov.kz** (Бюро нацстатистики) | Фактическая начисленная зарплата: по отраслям и регионам поквартально (с I кв. 2024 по II кв. 2026), по профессиям × отраслям и × регионам (апрель 2025 и 2026), национальная средняя и медиана | Работает |
| **qsamruk.kz** | Вакансии с вилками (госсектор, много рабочих профессий) | Работает |
| **hh.kz** | Вакансии всех отраслей, описание → льготы | Код готов (официальный API); **нужен бесплатный токен** dev.hh.ru. На живом API не запускался |
| **enbek.kz** | — | Поиск закрыт для ботов в robots.txt → только `import-csv` |
| PwC/EY/WTW, свои данные | любые срезы | `import-csv` |

Официальные данные до 2024 года у Бюро опубликованы в формате .xls (не читается стандартной библиотекой) — загружены только 2024–2026.
Профессиональная статистика Бюро (форма 2-Т) выходит раз в год в октябре–ноябре: следующий релиз — осенью 2027; `collect stat` подхватит его сам.

### Подключить hh.kz (один раз)
1. Зарегистрируйте приложение на https://dev.hh.ru/admin → `client_id`, `client_secret`.
2. В `config.json` впишите контактный email в `user_agent`, затем:
```bash
export HH_CLIENT_ID=...  HH_CLIENT_SECRET=...
python3 -m sbench collect hh --days 30
```
`"fetch_details": true` включает разбор текста вакансий (льготы; +1 запрос на вакансию).

## Справочники и фильтры
Отрасль (19 разделов ОКЭД) · профобласть (27, классификатор hh) · профессия (193 роли) + ~3 900 официальных профессий (НКЗ) через поиск ·
уровень · регион (все 20: 17 областей, включая Абай, Жетісу, Ұлытау, и города Астана, Алматы, Шымкент) · источник · опыт · период.
Списки показываются **целиком**, даже если по значению пока нет данных; ◆ — есть официальная статистика.
Новый фильтр: поле в `observations` (`sbench/db.py`) → `report.py` → `FACETS` в `sbench/dashboard/benchmark.js`.

## Импорт CSV
```bash
python3 -m sbench import-csv my_data.csv --source "enbek.kz"
```
Колонки: `title; salary_from; salary_to; currency; gross; date; category; role; industry; region; employer; experience; benefits`.
Обязательны `title` и `salary`/`salary_from`. Отрасли/регионы/профобласти приводятся к справочникам автоматически.

## Регулярный запуск
Вакансии живут ~30 дней, история копится только в вашей базе — запускайте раз в неделю:
```cron
0 7 * * 1  cd /путь/к/salary-benchmark && python3 -m sbench collect all && python3 -m sbench build
```

## Допущения, которые нужно проверить (`config.json`)
- **Налоги** — `tax` (по умолчанию правила с 1.01.2026: МРП 4 325, МЗП 85 000, ОПВ 10%, ВОСМС 2%, ИПН 10/15% с вычетом 30 МРП; работодатель: ОПВР 3,5%, СО 5%, ООСМС 3%, СН 6%). Сверьте с бухгалтерией; база СН и вычет в ИПН могли быть уточнены. «На руки» → gross пересчитывается точной обратной формулой.
- `fx_to_kzt` — курсы-заглушки; обновите.
- `sanity_bounds_kzt_month` — отсечка явного мусора (70 тыс.–8 млн ₸).
- qsamruk.kz: принято, что указанная зарплата — gross (на сайте не уточняется).

## Ограничения
Вакансии — **предложения** работодателей, официальные данные — **факт** (с премиями, до налогов); считаются и показываются раздельно.
По профессиям Бюро учтён верхний уровень отрасли (без подотраслей). Маппинг должностей подбирает роль из классификатора hh (193 роли);
для редких профессий точной роли может не быть — ориентируйтесь на ближайшую официальную профессию. Группы с n < 5 скрыты («н/д»).
